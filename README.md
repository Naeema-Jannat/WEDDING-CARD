# Fahim & Joyee Wedding Website

A minimal, responsive wedding invitation website with Pakistani wedding-inspired details.

## Preview locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Create a GitHub repository and upload `index.html`.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Use the default settings and click **Deploy**. Vercel will serve this as a static site.

You can also drag the project folder into a supported Vercel deployment workflow.

## Personalize before publishing
- Replace the "Date to be announced" and each event's date, time, and venue.
- Replace the story text and gallery photos with your own.
- The RSVP form is currently a visual demo. Connect Formspree, Google Forms, or a custom backend to collect guest responses.
- Photos and fonts are loaded from Unsplash and Google Fonts, so an internet connection is needed for those assets.
